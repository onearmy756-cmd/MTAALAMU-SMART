# Fundi Deploy — mwongozo mfupi

1. **Setup** Fundi Server kwenye LAN ya mteja (Ubuntu + docker-compose).
2. **Images** — weka ISO/WIM chini ya `server/images/`.
3. **Discover** MAC (`/computers/discover` au arp-scan).
4. **Deploy** — chagua OS + targets → WOL → PXE menu → install.
5. **Jobs** — fuatilia progress `/jobs`.
6. **AI (Ollama)** — chagua OS kwa specs (phase 2).
7. **Cloud** — dashboard ya wateja wengi (phase 2).

Phases: **P1** API+WOL+PXE menu · **P2** AI+backup+multicast · **P3** Cloud multi-tenant.
