⭐ MWANZO HAPA — Mfumo unafanyaje kazi (dakika 2)

Wachezaji 3: Wewe (msimamizi/mtaalamu), Mteja (anayetaka OS), na Agent (AI inayofanya kazi nzito). Agent HAIWEZI kuanza kitu bila idhini yako — hii ni HITL (Human-In-The-Loop).

👤 Wewe — Mtaalamu/Msimamizi
  • Unagundua computers za mtandao
  • Unachagua OS na unaidhinisha deploy (kitufe RUHUSU)
  • Unafuatilia progress na unaweza GHAIRI wakati wowote
🧑‍💻 Mteja
  • Anaomba OS mpya → anapata code RMT-XXXX-XXXX
  • Anafuatilia session yake kwa code (status inajionekana)
  • Hana uwezo wa kuanza install pekee yake
🤖 Agent (AI)
  • Inachanganua specs → inapendekeza OS sahihi
  • Baada ya idhini: inasakinisha OS → apps ZOTE za bundle kiotomatiki
  • Kila hatua inaandikwa kwenye feed ya chini (🧠 Agent Live)
1Gundua computers — chagua tab Computers, bonyeza "Gundua"
2Chagua OS — AI inapendekeza kulingana na specs + mahitaji
3Anza deploy — job inasubiri → bonyeza RUHUSU (HITL)
4Fuatilia — Jobs + Agent Live zinaonyesha kila hatua mpaka done
❓ Maswali ya kawaida

Deploy ni nini? Kusakinisha OS (Windows/Ubuntu) + programs muhimu kwenye computer moja au nyingi kwa mtandao.
Hitilafu ikitokea? Job inaonyesha "failed" na sababu — rekebisha kisha anzisha upya.
Naweza kusimamisha? Ndiyo — kitufe GHAIRI kwenye kila job inayoendesha.
Apps ni zipi zinawekwa? Bundles: home/office/developer/school/cybercafe (Chrome, LibreOffice, VS Code n.k.) — zinaonekana kwenye OS INSTALL.
